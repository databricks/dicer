# Fonts

`DMSans-Variable.woff2` is the DM Sans variable font (weights 400–800, normal
style, Latin subset), self-hosted so the page makes no request to Google
Fonts at load time. Source: `https://fonts.gstatic.com/s/dmsans/v17/...`
(the exact file Google's CSS2 API serves for this weight range). Licensed
under the SIL Open Font License 1.1 — see `OFL.txt`.
